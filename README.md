# bdoffer.online static preview

This package contains the updated static landing page, real operator logo assets, responsive UI, contact inquiry form, coming-soon action feedback, separate informational pages, and Facebook-ad-safe informational copy.

The site is static. The inquiry form shows a local confirmation and does not transmit personal data until a backend endpoint is configured. Admin/token functionality from the separate admin project was not guessed or bundled because the target repository was empty and no verified token was available.
